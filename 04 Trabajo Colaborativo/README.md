# Unidad 4 - Trabajo Colaborativo

En esta unidad se trabajaron conceptos de control de versiones utilizando Git y GitHub.

## Contenido

* Conceptos básicos de Git y GitHub.
* Repositorio local y repositorio remoto.
* Área de trabajo, staging y commits.
* Uso de 'git add', 'git commit', 'git push' y 'git pull'.
* Creación y uso de ramas.
* Merge de ramas.
* Uso del archivo '.gitignore'.
* Buenas prácticas de trabajo colaborativo.


## Trabajo práctico

Como actividad integradora se creó este repositorio de Programación I, se organizaron las prácticas de las unidades anteriores y se utilizó GitHub Desktop para registrar y publicar los cambios en GitHub.

Como el trabajo práctico de esta unidad consiste en aplicar estos conceptos sobre el propio repositorio, se creó este archivo README.md para documentar el trabajo realizado.
